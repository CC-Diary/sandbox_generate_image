# 换脸干货封面 · cover-face-title

> 一个专做「干货教程风封面」的 AI Skill。你给它一张人脸参考图、两行标题、一句背景主题，它输出一张小红书味十足的手账拼贴封面：贴纸化的人物、亮绿黑边的卡通大标题、与主题呼应的场景背景。

---

## 这是什么

做干货内容的人，最容易亏在封面上。

内容写得再扎实，封面没有辨识度，用户在信息流里划过去只要 0.5 秒。而绝大多数人的封面问题是同一个：**看不出这是谁、看不出讲什么、看不出凭什么点**。

这个 Skill 就锁死这三件事：

| 用户的心声 | 封面要给的答案 | 具体做法 |
|---|---|---|
| 这是谁？ | 一张让人记住的脸 | 人脸参考图 → 白色粗描边贴纸化，从背景里剥离出来 |
| 讲什么？ | 一句说人话的标题 | 加粗卡通黑体 + 亮绿黑边，上下对称占满宽度 |
| 凭什么点？ | 一个值得点的理由 | 主标题承诺利益，副标题降低门槛（如「新手直接抄作业」） |

三者缺一，封面就退化成普通配图。

---

## 它长什么样

默认风格是**新媒体干货手账拼贴风**，三层结构从下往上叠：

```
┌─────────────────────────────┐
│  主标题（亮绿底黑描边 · 占满宽度）  │
│                             │
│   [ 贴纸化人物 · 白色粗描边 ]     │  ← 视觉重心，占画面 1/2~3/5
│     皱眉认真 / 手指前指          │
│                             │
│  主标题（与顶部对称呼应）          │
└─────────────────────────────┘
   背景层：与主题相关的中景，轻度虚化
   装饰层：2-3 个卡通贴纸（钱袋 / AI 气泡 / 数据节点）
```

人物被一圈**白色粗描边**包住，像贴纸贴上去一样跟背景脱开——这是整个风格的识别特征，也是它跟普通 AI 配图拉开差距的地方。

---

## 它能帮你做什么

- 做知识付费 / 干货教学，需要一眼看出「这是个讲方法的号」→ 生成系列化封面
- 做工具测评、AI 教程、副业分享 → 背景自动转译成对应场景（桌面 + 数据图表）
- 已经在做号，想统一封面视觉但请不起设计 → 一套风格词库 + 固定构图，出图稳定
- 想突出真人 IP，又不想每张都重拍 → 同一张人脸参考图，反复换主题出图

---

## 你需要准备什么

**四项必需，缺哪项它只追问哪项，不会一次问一堆：**

| 输入 | 说明 |
|---|---|
| **人脸参考图**（1 张） | 替换封面人物的脸。请只使用你自己或已获授权的照片 |
| **主标题文案** | 顶部与底部对称排布的核心标题 |
| **副标题文案** | 侧边引导语，如「新手运营 直接抄作业」 |
| **背景主题描述** | 如「教别人做自媒体」。不给时，它从主标题语义推导 |

**可选项：** 画幅（默认 3:4）、人物姿态表情（默认皱眉认真 + 手指前指）、整体风格（点名即切换）。

> ⚠️ 关于人脸：本 Skill 仅处理你主动提供的素材。上传他人的照片前请先确认已获得肖像使用授权——这既是法律要求，也是平台审核的红线。

## 工作流程

1. **收集输入** — 按四项必需逐项确认，最多补问一轮
2. **组装生成描述** — 风格词库 + 画幅 + 三层构图 + 逐字写入的标题文案
3. **生成出图** — 每次 1 张；不通过质量测试就静默调整重做，最多 2 次
4. **交付** — 附上可继续微调的方向（标题字号、贴纸元素、背景密度）

### 它自己的验收标准（可证伪）

把成图缩到**拇指大小**再看一遍：

- 人脸轮廓还认得出吗？
- 主标题还读得全吗？
- 副标题至少能认出一半吗？

任一不满足就判失败，回去调 prompt 重做，不许直接交付给你。

## 风格路由

| 你说什么 | 它走哪条路 |
|---|---|
| 什么都不说（默认） | 干货手账拼贴风，加载完整风格词库与构图规范 |
| 「做成极简风」/「3D 风」/「纯文字封面」 | 按你的描述执行，只保留「人脸替换 + 双标题」这个骨架 |

## 安装 / 使用

**首选：剪映小云雀（xyq.jianying.com）**

本 Skill 是在小云雀创作 Agent 中调试成型的，`sandbox_generate_image` 即小云雀沙箱内的生图工具。

1. 打开小云雀创作 Agent
2. 上传本 Skill 文件夹（压缩为 zip）
3. 对话里直接说：「帮我做张封面，人脸图我传给你，主标题是 XXX，副标题是 XXX，背景讲的是 XXX」

**其他：Claude Code / WorkBuddy 等支持 `SKILL.md` 的助手**

SKILL.md 用的是标准格式，可以直接加载。但生图工具名需要替换成目标平台的对应工具（WorkBuddy 下为 `ImageGen`，人脸参考图走 `image1` 参数）。

```
# WorkBuddy 用户级目录（跨项目可用）
~/.workbuddy/skills/cover-face-title/

# Claude Code 用户级目录
~/.claude/skills/cover-face-title/
```
