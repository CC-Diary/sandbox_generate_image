# 干货手账拼贴风：风格规范与用词库

本技能默认风格的唯一事实源。落 prompt 前通读本文件，把「三层构图规范」与「用词库」写进生成描述。

## 三层构图规范（自下而上）

### 背景层
- 室内或主题场景的**中景**，做轻度虚化，作为氛围铺垫不抢主体。
- 依据用户背景文字转译：教程/自媒体类 → 桌面笔记本电脑露出数据图表；美食类 → 厨房操作台与食材；职场类 → 办公桌与文件。转译成具体可画的物件，不写抽象概念词。

### 人物层
- 人物置于画面中央视觉重心，占画面高度约 1/2 至 3/5。
- **白色粗描边贴纸化处理**：人物轮廓外扩一圈白色描边，与背景剥离，形成「贴纸贴上去」的手账质感。这是本风格的识别特征，不可省略。
- 姿态默认「皱眉认真表情、右手拇指或食指前指」；发型、服饰、耳饰等细节随人脸参考图适配。

### 文字贴纸层
- **主标题**：顶部与底部对称排布，加粗卡通黑体，亮绿底色黑描边（或黑字亮绿底），字号最大，占满宽度。
- **副标题**：侧边竖排或斜放，撞色粗体（如左上白右下黄的色块分割），字号约为主标题的一半。
- **装饰贴纸**：2-3 个卡通贴纸，与背景主题呼应（通用备选：绿色钱袋、AI 对话气泡、淡绿色数据节点、箭头、对勾）。

## 用词库

**整体基调**：新媒体干货感、手账拼贴、网感明快、接地气、教程亲切引导感
**主色调**：清新绿 + 黑 + 浅灰蓝；点缀黄、白
**人物处理**：贴纸化描边、留白描边、剥离背景、轮廓外扩白边
**标题处理**：加粗卡通黑体、亮绿黑边、上下对称包围、撞色色块副标题
**构图**：居中对称、隐形包围式边框、层次逐级递进

## 落 prompt 前自检
- 是否三层齐全（背景 / 贴纸人物 / 文字贴纸）？
- 白色描边是否明确写入？
- 主标题是否上下对称排布？
- 装饰贴纸是否 2-3 个且呼应主题？
